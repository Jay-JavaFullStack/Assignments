1. Write the Git command for each: initialize a repo, stage all files, commit with a message, push to remote, pull latest changes.

->  (I) initialize a repo => git init

    (II) stage all files => git add .

    (III) commit with a message => git commit -m "your message"

    (IV) push to remote => git push

    (V) pull latest changes => git pull




2. What is the difference between git fetch and git pull? Answer in 2 lines.

->  Git Fetch => downloads the latest changes from the remote but doesn't merge them into your current branch.

    Git Pull => downloads the latest changes and automatically merges them into your current branch.




3. Create a new GitHub repository, push any small text file from your local system, and share the repo link.

->  Create a repository on GitHub and push a text file using:

    git init
    git add test.txt
    git commit -m "Added test file"
    git branch -M main
    git remote add origin https://github.com/Jay-JavaFullStack/Assignments.git
    git push -u origin main




4. What is the difference between a Fork and a Pull Request? Answer in 2 lines.

->  Fork => is making your own copy of someone else's repository so you can freely make changes without affecting the original.

    Pull Request => is a request you send to the original repository asking them to add your changes into their project.




5. Create a new branch named feature-test, make one commit on it, and merge it back to the main branch. Write the commands you used.

->  (I) Create and switch to a new branch => git checkout -b feature-test

    (II) Make changes and commit => git add .
                                    git commit -m "Added changes in feature-test"

    (III) Switch back to main branch => git checkout main

    (IV) Merge feature-test into main => git merge feature-test
