1. Write the full form and one-line use of: HTTP, HTTPS, FTP, SMTP.

->  (I) HTTP (HyperText Transfer Protocol) => Used to send and open web pages on the internet.

    (II) HTTPS (HyperText Transfer Protocol Secure) => Same as HTTP but keeps data safe and encrypted.

    (III) FTP (File Transfer Protocol) => Used to upload or download files between computers over the internet.

    (IV) SMTP (Simple Mail Transfer Protocol) => Used to send emails from one server to another.




2. What is the difference between IPv4 and IPv6? Answer in 2 lines.

->  (I) IPv4 => Uses short 32-bit addresses with numbers and dots, has limited addresses, and is slower and less secure.
                Example = (192.168.1.1)

    (II) IPv6 => Uses long 128-bit addresses with numbers and letters, has almost unlimited addresses, and is faster and more secure.
                 Example = (2001:0db8::1)

4. What do these HTTP status codes mean: 200, 301, 404, 500, 403?

->  (I) 200 => OK (Everything is fine, the page works.)

    (II) 301 => Moved Permanently (The page has shifted to a new address.)

    (III) 404 => Not Found (The page does not exist.)

    (IV) 500 => Internal Server Error (Something is broken on the server.)

    (V) 403 => Forbidden (You are not allowed to see this page.)




5. Explain DNS hierarchy (root, TLD, domain, subdomain) with www.google.com as an example.

->  Root (.) => Top of the system, points to TLDs.

    TLD (.com) => Category of the site.

    Domain (google) => Main website name.

    Subdomain (www) => Specific part of the site.
