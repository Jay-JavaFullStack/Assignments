1. Write a short paragraph in your own words defining what a 'program' is and give one real-life example from any app you use daily (like Instagram, Zomato, or Paytm).

->  Program => A program is a set of instructions written by a programmer that tells a computer what to do step by step.
               It helps the computer perform tasks automatically, like calculations, showing information, or connecting people, without a human doing it manually each time.

    Real-life example => Instagram is a program. When you open the app, it runs instructions to show you photos and videos, let you like or comment on posts, and send messages to friends — all happening because of code written by developers.
